# Trip Details Page

Each Trip Details page should have the `title` and `date` at the top of the page. 

After, each trip segment should be displayed in order in a single column. 

For Markdown sections, the title should be displayed at the top of the section and the markdown content should be displayed below the title. 

For Media sections, they should be displayed in a gallery view that has arrow buttons to allow scrolling to next media item. If the user was to click on the media item itself, the gallery should show full screen
